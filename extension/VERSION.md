## Installation & Setup

### Requirements
- VS Code 1.95.0 or later
- GitHub Copilot Chat extension
- PowerShell (Windows) or Bash/Zsh (Linux/macOS)

### Quick Start
1. Install Terminal Orchestrator v4.0.0
2. Restart VS Code  
3. Open GitHub Copilot Chat
4. Test: `@terminal-orchestrator listTerminals`

### Professional Usage
```
// Create development environment
@terminal-orchestrator startDevStack

// Execute safe command sequences
@terminal-orchestrator safeRunSequence {
  "name": "deploy", 
  "commands": ["npm ci", "npm run build", "npm test"]
}

// Monitor and optimize
@terminal-orchestrator healthCheck
@terminal-orchestrator selectOptimalTerminal
```
