# 🎯 Guide d'Utilisation Copilot Terminal Tools

Ce guide vous montre comment utiliser efficacement les outils de terminal avec GitHub Copilot dans VS Code.

## 🚀 Installation Rapide

```bash
# 1. Cloner ou télécharger le projet
cd c:\jeanluc\vscode_mcpserver

# 2. Installation complète automatique
npm install
npm run build
npm run install-vscode

# 3. Redémarrer VS Code
```

## 🎮 Commandes Copilot Disponibles

### 🖥️ Gestion des Terminaux

```
@copilot liste tous les terminaux actifs
@copilot crée un nouveau terminal nommé "react-dev"
@copilot supprime le terminal "test"
@copilot ferme tous les terminaux inactifs
```

### ⚡ Exécution de Commandes

```
@copilot exécute "npm install" dans le terminal principal
@copilot lance "npm run dev" en arrière-plan
@copilot teste le projet avec "npm test"
@copilot build le projet avec "npm run build"
```

### 🔧 Configuration Avancée

```
@copilot crée un terminal PowerShell dans le dossier backend
@copilot configure un terminal avec variables d'environnement
@copilot surveille les performances du terminal React
@copilot nettoie les terminaux zombies
```

### 🧠 Intelligence Contextuelle

```

@copilot détecte les processus bloqués et les corrige
```

## 💡 Conseils d'Utilisation

### 🎯 Commandes Optimales

- **Soyez spécifique** : "crée un terminal React" plutôt que "terminal"
- **Nommez vos terminaux** : facilite la gestion avec plusieurs projets
- **Utilisez le contexte** : mentionnez le projet ou framework

### ⚡ Performances

- **Réutilisez les terminaux** existants quand possible
- **Fermez les terminaux** inutilisés pour optimiser les ressources
- **Surveillez les métriques** pour détecter les ralentissements

### 🛡️ Sécurité

- **Vérifiez les commandes** avant exécution dans des terminaux de production
- **Utilisez des environnements** séparés pour dev/test/prod
- **Sauvegardez** vos configurations importantes

## 🚨 Résolution de Problèmes

### Erreur : "MCP Server not found"

```bash

# Vérifiez la configuration VS Code
cat "%APPDATA%\Code\User\mcp.json"

# Redémarrez VS Code
```
